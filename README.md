### 🧠 Engineering Principles

- **Production-Ready by Default:** Database migrations with Flyway, observability with Actuator & Prometheus, and Dockerized environments from commit one.
- **Realistic Integration Testing:** No false confidence from mock-only tests. Core persistence and infra are validated with **Testcontainers** against real PostgreSQL and Redis instances.
- **Architectural Discipline:** Strict domain boundaries and loose coupling using **Spring Modulith** and Clean Architecture patterns before jumping into distributed complexity.
